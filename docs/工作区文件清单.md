## 七、关键依赖关系

```
需求文档
   ↓
计费引擎（core/billing.ts）──→ 后端 BillingEngine.java（必须逐条一致）
   ↓
业务服务层（data/service.ts）──→ 后端 Service 层
   ↓
UI 页面（views/）──→ 员工端保留 / 管理端 PC 换若依
```

**最关键的约束**：计费引擎是唯一「前后端各写一遍且必须结果相同」的部分。其余都是单向迁移。
